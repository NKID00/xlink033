# xlink033

Ultra-affordable debug probe built around the 30 cent MCU CH32X033F8P6, featuring:

- Bootstrap select button, so you won't need yet another probe to unbrick the probe itself!
- 5V and 3V3 dual switchable current-limited output
- RVSWD/SDI, JTAG/SWD, UART and RST signal
- Full-speed USB
- Link and activity indicator LED
